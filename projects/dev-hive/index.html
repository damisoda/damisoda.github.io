다룬 문제참여한 일구현 선택검증과 한계

어떤 문제를 다뤘나요?

AI 콘텐츠는 많지만 자신의 수준에서 무엇부터 배울지 정하기 어렵습니다. 흩어진 콘텐츠를 주제와 선후 관계로 정리하고, 다음 학습 자료를 추천하는 흐름을 만들었습니다.

어떤 일에 참여했나요?

팀 리드로 그래프(Layer 2)와 서비스 영역을 맡았습니다. AI 코딩 도구와 함께 FastAPI API·온보딩·서비스 통합을 진행하고, 로컬 모델 활용과 그래프 고도화 방향을 검토했습니다.

서비스는 어떻게 동작하나요?

  1. 수집·품질 검사
  2. 태깅·임베딩
  3. 지식그래프 구성
  4. 개인화 추천

유료 호출 전에 품질 검사

빈 본문·중복·허용 소스를 먼저 검사해 수집 품질과 처리 비용을 관리했습니다.

원문 검색과 가공 콘텐츠 분리

원문을 임베딩해 검색 근거로 유지하고, 가공 학습 카드는 별도 저장·캐시하도록 구성했습니다.

추천과 운영을 함께 연결

FastAPI·PostgreSQL·Next.js를 연결하고 Docker와 Mac mini 환경에서 배포했습니다.

무엇을 확인했나요?

공개 README에 데이터 처리 현황, 그래프 평가 수치, 추천 구조와 배포 절차를 기록했습니다. PR로 구현 상태를 정정한 이력도 남겼습니다.

확인한 범위와 남은 한계

GraphSAGE는 학습 파이프라인까지만 구축했으며 추천에는 반영하지 않았습니다. 공개 배포 기록은 당시의 상태이며 현재 가동 여부를 의미하지 않습니다.
