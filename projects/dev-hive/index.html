문제 해결다룬 문제참여한 일시스템 구조구현 선택검증과 한계

문제 해결

콘텐츠 66%가 대주제 7개에 몰린 catch-all 문제를 k-means 잔여 분할로 해소

문제 원인

  • 팀이 2패스 구조로 고아 노드를 줄인 뒤에도 콘텐츠의 66%(764건)가 하위 주제 없이 대주제 7개에 평면으로 매핑돼 있었습니다. 그래프가 사실상 7갈래였습니다.
  • 잔여 콘텐츠를 연결요소로 묶는 방식은 거대한 한 덩어리가 되거나 전부 고아가 되는 양극단으로 갈라졌습니다.
  • 추천의 선행관계 경로 점수가 대표 노드를 찾지 못해 모두 중립값(0.5)으로 계산됐습니다.

해결 과정

  • catch-all 기준 재정의: 하위 노드에 속하지 않고 대주제에 직접 붙은 잔여 콘텐츠를 기준으로, 여러 번 실행해도 같은 결과가 나오게 재분할했습니다.
  • 균형 분할: 연결요소 묶기 대신 spherical k-means(k = round(n/45))를 썼습니다.
  • 이상치 가드: 중심 유사도 0.45 미만인 콘텐츠는 강제 편입하지 않고 새 주제 후보로 남겼습니다.
  • 회귀 게이트: 그래프를 다시 만들 때 목적함수 J가 0.02 넘게 떨어지면 실패하도록 했습니다.
  • 테스트: test_auto_hkg 22개를 포함해 전체 372개가 통과했습니다. 로컬 재구축 DB에서 전후를 측정했습니다.

결과

  • 하위 주제 노드 68개가 생겼습니다(예: 'AI 메모리&상태관리', 'Claude Code 실전활용').
  • coverage가 0.34 → 0.999, 그래프 목적함수 J가 0.525 → 0.689로 올랐고, 고아 노드는 0개입니다.
  • 선행관계 경로 점수가 추천 후보 400개 중 292개에서 작동하게 됐습니다.

어떤 문제를 다뤘나요?

AI 콘텐츠는 많지만 자신의 수준에서 무엇부터 배울지 정하기 어렵습니다. 흩어진 콘텐츠를 주제와 선후 관계로 정리하고, 다음 학습 자료를 추천하는 흐름을 만들었습니다.

어떤 일에 참여했나요?

팀 리드로 그래프(Layer 2)와 서비스 영역을 맡았습니다. AI 코딩 도구와 함께 FastAPI API·온보딩·서비스 통합을 진행하고, 로컬 모델 활용과 그래프 고도화 방향을 검토했습니다.
