오늘의 커리어와 돈을 한눈에

검증 이력과 저금통 성장 상태, 지금 쓸 수 있는 돈, 세금·경비·여윳돈을 한 화면에서 확인합니다. 이력 연동·정산 관리·금융 연결·미래 소득으로 이어집니다.

데모 체험

첫 화면의 ‘건너뛰기’로 둘러보거나, ‘다음’으로 시작해 이력을 모으는 과정부터 살펴볼 수 있습니다. 하단의 홈·가계부·미션·커리어·미래 탭을 눌러보세요.

저장소의 예제 응답을 사용하는 화면 체험입니다. 실제 금융기관 연결·거래·모델 호출은 하지 않습니다. 상품·금액·예측 결과는 예시입니다.

앱 화면·체험다룬 문제참여한 일구현 선택검증과 한계

어떤 문제를 다뤘나요?

수입 시점과 금액이 불규칙한 긱워커에게 월급 기준의 예산 관리는 맞지 않습니다. 입금 한 건을 다음 생활과 목표에 어떻게 배분할지 설명하는 서비스를 만들었습니다.

어떤 일에 참여했나요?

앱의 탭 구성과 데모 사용자 흐름, 로컬 모델 사용 조건을 정했습니다. AI 코딩 도구와 함께 디자인을 백엔드에 연결하고 봉투 UI·미션·레벨업 경험을 개선했습니다.

서비스는 어떻게 동작하나요?

  1. 이력 모으기·일감 확인
  2. 페르소나 판독
  3. 봉투 제안·사용자 승인
  4. 미션·목표·미래 계획

판단은 모델, 금액은 코드

EXAONE은 페르소나와 배분 우선순위를 판단하고, 세금과 합계는 결정론적으로 계산하도록 분리했습니다.

승인과 결과를 기록

사용자의 승인·조정·거절을 이벤트로 남겨 다음 제안의 근거가 되도록 연결했습니다.

모델의 약점도 평가에 포함

골든셋에서 규칙과 모델을 비교하고, 근거가 부족하면 판단을 기권하는 안전 게이트를 두었습니다.

무엇을 확인했나요?

하나 청년 금융인재 양성 프로젝트 우수상. 공개 저장소에 계층 구조, 모델 역할, 골든셋 평가 기록과 검증 명령을 정리했습니다.

확인한 범위와 남은 한계

공모전 데모입니다. 공개 평가에서는 모델의 원시 정확도가 단순 규칙보다 낮은 조건도 확인됐습니다. 실제 금융기관의 심사나 실계좌 연동 성능을 입증한 것으로 소개하지 않습니다.
